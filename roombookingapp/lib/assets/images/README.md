# Thư mục ảnh phòng

Thư mục này chứa các ảnh phòng cho các khách sạn.

## Cách thêm ảnh:

1. Đặt tên file ảnh theo format đã được định nghĩa trong `init_hotels.dart`
2. Các file ảnh sẽ được tham chiếu trong code với đường dẫn `assets/images/[tên_file]`
